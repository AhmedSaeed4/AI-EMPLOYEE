# Everyone Asks What Their AI Should Do. We Started With What It Can Never Do.

Before it sent a single email, ours got a rulebook.

Written before anything was automated:

**1. It never moves money.** It chases invoices and flags late payers — but not one dollar moves without human approval. New recipient? Same stop.

**2. It never publishes live.** Every post is drafted and queued for sign-off. (This one included.)

**3. It never improvises on sensitive words.** "Urgent." "Invoice." "Payment." It escalates instead of answering — a fast wrong reply costs more than a slow right one.

**4. It never acts unlogged.** Every action leaves a record. Trust isn't a feeling here; it's an audit trail.

The twist: those rules are why everything ELSE runs unsupervised. Money, publishing, judgment — fenced off. The rest runs 24/7, and nobody loses sleep.

Constraints aren't the tax on automation. They're the license for it.

## Key Takeaways
- Write the "nevers" before automating task one
- Fence off the risky 5% and the other 95% can run unsupervised
- Trust is an audit trail, not a feeling
